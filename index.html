Configuration de l'IA

Attention : GitHub Pages est un hébergement statique. L'appel API part donc directement de ton navigateur. La clé reste uniquement en mémoire de session, mais elle peut être inspectée pendant l'utilisation. Pour un site public multi-utilisateur, il faut un backend sécurisé.

Si ton compte n'a pas accès au modèle proposé, saisis un identifiant disponible dans ta console Anthropic.

Mettre le site sur GitHub Pages

  1. Télécharge ce fichier et renomme-le exactement index.html.
  2. Sur GitHub, crée un nouveau dépôt, par exemple anatorevise.
  3. Ajoute index.html à la racine du dépôt, puis valide avec Commit changes.
  4. Ouvre Settings → Pages.
  5. Dans Build and deployment, choisis Deploy from a branch.
  6. Sélectionne la branche main, le dossier /(root), puis clique sur Save.
  7. Après quelques minutes, le site sera disponible à l'adresse https://TON-PSEUDO.github.io/anatorevise/.
Ne mets jamais ta clé API dans le code HTML ni dans le dépôt. Saisis-la uniquement dans la fenêtre « Configuration » après avoir ouvert le site.
